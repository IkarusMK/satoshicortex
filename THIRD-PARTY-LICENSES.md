# Third-party components

This repository contains **no third-party source code**. The Dockerfiles
download the official releases at build time and verify their signatures
before anything enters an image.

It does contain **third-party DATA**: the country outlines of the world map
(`app/web/welt.svg`, generated from Natural Earth). See below.

As soon as **prebuilt images** are distributed, however, those images contain
third-party binaries. The following licences apply to them; the licence texts
are inside the images under `/usr/share/licenses/`.

| Component | Licence | Origin |
|---|---|---|
| Bitcoin Core | MIT | https://github.com/bitcoin/bitcoin |
| LND | MIT | https://github.com/lightningnetwork/lnd |
| Lightning Terminal (litd) | MIT | https://github.com/lightninglabs/lightning-terminal |
| Tor | BSD-3-Clause | https://gitlab.torproject.org/tpo/core/tor |

| Debian base images and packages | various (free) | https://www.debian.org |
| Python dependencies of the application | see `app/backend/requirements.txt` | — |

Of these, what is currently shipped is **Bitcoin Core, LND and Tor**. The
licence text sits inside the respective image under `/usr/share/licenses/`, and
CI verifies on every build that it really is there and readable.

The web interface brings **no** third-party libraries with it: no npm, no
bundler, no loading from a CDN. Everything the browser loads lives under
`app/web/` — the price chart is hand-drawn SVG, so is the world map.

## Mining pool identifiers

The file `pools-v2.json` comes from the repository
[mempool/mining-pools](https://github.com/mempool/mining-pools) and is MIT
licensed. It is a **standalone data repository** and not part of the mempool
application.

## Country outlines of the world map

`app/web/welt.svg` is generated by `tools/karte_bauen.py` from two
[Natural Earth](https://www.naturalearthdata.com) datasets:

* `ne_110m_admin_0_countries` — the outlines
* `ne_50m_admin_0_tiny_countries` — points for countries that would have no
  area at all at this resolution (Singapore, Hong Kong, Malta and others)

Natural Earth is **public domain** and explicitly waives any attribution
requirement. The source is credited anyway — here, in the header of the
generated SVG file, and in the web interface below the map.

## Region outlines

You can click a country; its states, cantons or provinces then
appear. The outlines for that live as one file per country under
`app/web/regionen/` and are generated by `tools/regionen_bauen.py` from a third
Natural Earth dataset:

* `ne_10m_admin_1_states_provinces` — 4,596 regions across 241 countries

The medium dataset (`ne_50m_admin_1_...`) was not an option: it contains only
nine countries, and Germany is not among them.

Which name in the IP list belongs to which outline is recorded in
`app/data/regionen.json` and generated by `tools/regionen_zuordnen.py`. The
mapping works through coordinates, not spellings: for France not a single name
matches literally, because Natural Earth lists departments there while DB-IP
lists the regions of the 2016 reform.

## IP-to-country table

The world map needs a location for every address. That happens **entirely
locally**: `tools/geo_bauen.py` builds a compact table at image build time from
the free city list of [DB-IP](https://db-ip.com/db/download/ip-to-city-lite),
and that table sits inside the image. In operation **not a single request**
goes outside for it — otherwise a third party would receive the node's complete
peer list.

The city list rather than the country list: only it carries the
region, and the region is what fills in the states when you click a country.
Nothing about the city itself is **taken over** — what is stored is country and
region, not the town. That is the accuracy the free list honestly provides.

The list is licensed **CC BY 4.0**. Attribution is given here and visibly in
the web interface below the map, including the vintage of the edition used.

## Adopted design rules

From **pbakaus/impeccable** (Apache-2.0) come, in substance, the division of
interfaces into modes (Persuade/Operate/Read/Experience), the list of browser
defaults that ought to be set from your own palette, and the rule to check in
bounded passes rather than in a loop. From **emilkowalski/skill** (MIT) comes,
in substance, the decision gate in front of every animation.

No text and no code was adopted, only the rules in our own wording; they are
stored as skills in AICortex. They are credited here regardless, because where
a rule came from is part of it.
